# Product and privacy decisions (Phase 1)

Assumed during build; please confirm or change.

- **Assignment:** one person per section.
- **Joining:** accounts are usernames with passwords; people join a project with a single-use invite code from the owner (valid 1, 7 or 30 days; revocable).
- **Passwords:** no self-service reset; the owner resets them from the Supabase dashboard (see SETUP.md).
- **Script input:** pasted text or `.txt` only (200 KB max). The original text and filename are saved per project; sections split at lines containing only `---` link to the live recording sections, so text edits appear in the script view.
- **Backing audio:** played for reference while recording; the saved take is the microphone only.
- **Who can listen:** every member of a project can play current takes in that project.
- **Who can record:** the owner, and the person a section is assigned to.
- **Who can delete:** the owner can delete any take, section, member or the project. Cast can delete their own takes and leave a project.
- **Pauses:** the owner can add timed pauses (0.1 to 60 s) between sections in the Summary tab. They are part of the script order, are not recorded, and play back in Play all.
- **Editing text:** the owner and the person a section is assigned to can edit its script text. Doing so deletes the section's current take (after a confirmation), so it must be recorded again.
- **Old takes:** kept when someone re-records (not visible in the app); deleting a take removes them too.

**Still to decide:** how long projects and recordings are kept, and the consent wording shown to people whose voices are recorded (plus how they request deletion).
